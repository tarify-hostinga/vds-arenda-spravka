Коротко

Расширенная поддержка Windows Server 2012 R2 закончилась в октябре 2023 года: обновления безопасности для него больше не выходят. Сервер на этом выпуске продолжает работать, но каждая новая найденная уязвимость остаётся открытой навсегда. Выпуск не получает исправлений безопасности с октября 2023 года.

Конспект по разделам

Что значит выпуск без обновлений

Разница между старым и поддерживаемым выпуском не в скорости и не в интерфейсе, а в том, что происходит после обнаружения уязвимости. Последняя строка важна для компаний, которые хранят персональные данные: система без обновлений плохо сочетается с требованиями к защите, см. персональные данные на VDS.

Почему такие серверы всё ещё живут

Рабочий компромисс для первой причины: оставить программу на изолированной машине без доступа из интернета, а всё остальное перенести на поддерживаемый выпуск. Это снижает риск, не ломая работу.

  • Программа не работает на новых выпусках.
  • Некому заниматься.
  • Боятся сломать.
  • Думают, что экономят.

Вопросы и ответы

Когда закончилась поддержка Windows Server 2012 R2?

В октябре 2023 года. С этого момента обновления безопасности для выпуска не выходят.

Можно ли арендовать сервер с Windows Server 2012?

У части провайдеров выпуск ещё есть в образах. Брать его стоит только под программу, которая не работает на новых версиях.

Что делать, если программа работает только на старом выпуске?

Изолировать машину: закрыть доступ из интернета, вынести её в отдельный сегмент и не хранить на ней персональные данные.

Насколько сложно перенести данные на свежий выпуск?

Основное время уходит не на перенос, а на проверку совместимости программ. Для трёх-четырёх программ это обычно один рабочий день.
