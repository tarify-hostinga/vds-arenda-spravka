Коротко

Передача файлов на сервер идёт четырьмя способами, и служба FTP из них самая старая и самая рискованная: она передаёт пароль открытым текстом. В большинстве случаев задача решается пробросом диска в сеансе или общей папкой. Для разовой передачи хватает проброса локального диска в сеансе, для регулярной нужен отдельный доступ.

Вопросы и ответы

Как быстро перекинуть файл на арендованный сервер?

Через проброс локального диска в сеансе удалённого стола: файл перетаскивается, служба передачи файлов для этого не нужна.

Безопасен ли обычный FTP?

Нет, он передаёт логин и пароль открытым текстом. Для доступа из чужих сетей используют защищённые варианты.

Как дать доступ к одной папке внешней системе?

Создать отдельную учётную запись с правами только на эту папку и без права входа в систему, а доступ ограничить адресами.

Где хранить файлы, с которыми работают сотрудники?

В общих папках на сервере с разграничением прав. Отдельная служба передачи файлов для этого обычно не требуется.
