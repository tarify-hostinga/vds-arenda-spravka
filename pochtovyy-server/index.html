Почтовый сервер на VDS: коротко и с данными

Конспект страницы: 5 разделов коротко, данные на 14 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Почтовый сервер на VDS.

Коротко

Поднять почтовый сервер на VDS несложно, сложно добиться, чтобы письма доходили: почтовые службы судят об отправителе по записям домена и по репутации адреса, а новый адрес для них подозрителен по умолчанию. Поэтому письма от учётной системы чаще отправляют через внешний сервис. Для доставки нужны PTR, SPF, DKIM и DMARC, иначе письма уходят в спам даже с чистого сервера.

Конспект по разделам

Что проверяет получатель

Запись PTR нельзя сделать самому: обратная зона принадлежит владельцу адреса, то есть провайдеру. Запрос оформляется в поддержке и выполняется для выделенного адреса, см. IP-адрес сервера.

Почему исходящий порт бывает закрыт

Исходящий порт 25 это канал, по которому серверы передают почту друг другу, и он же главный инструмент рассылки спама с арендованных машин. Поэтому многие провайдеры закрывают его по умолчанию. Отсюда порядок: сначала вопросы провайдеру про порт и обратную запись, потом установка программ.

  • На новых аккаунтах порт обычно закрыт.
  • Открытие через поддержку.
  • Приём почты порт 25 не требует.
  • Внешний сервис отправки порт 25 не использует.

Вопросы и ответы

Почему письма с сервера попадают в спам?

Чаще всего нет обратной записи PTR или подписи DKIM. Вторая причина это новый адрес без истории отправки.

Можно ли отправлять письма из 1С без своего почтового сервера?

Да, через внешний сервис отправки по SMTP. Это самый простой путь и он не требует открытого порта 25.

Кто прописывает запись PTR?

Только провайдер и только для выделенного адреса. Запрос оформляется в поддержке.

Сколько ресурсов нужно почтовому серверу?

Сам обмен письмами нетребователен, место занимают архивы ящиков и проверка на спам. Два гигабайта памяти это разумный минимум.
