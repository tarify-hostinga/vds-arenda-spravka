Коротко

SSH на Windows Server включается как компонент системы и даёт привычную консоль тем, кто пришёл из мира Linux. Но для администрирования Windows есть штатное удалённое управление, поэтому службу поднимают под конкретные задачи, а не по привычке. Служба нужна под копирование файлов скриптом и привычную консоль, а не для общего администрирования.

Вопросы и ответы

Есть ли SSH в Windows Server из коробки?

Служба входит в состав системы и включается как дополнительный компонент. Отдельно ничего скачивать не нужно.

Нужен ли SSH, если есть удалённый рабочий стол?

Обычно нет. Его включают под копирование файлов скриптом, доступ из систем сборки или привычку работать в консоли.

Можно ли входить по ключу вместо пароля?

Да, открытая часть ключа кладётся в профиль пользователя, после чего вход по паролю закрывают.

Открывать ли порт SSH в интернет?

Нет. Его ограничивают адресами или защищённым каналом, как и порт удалённого рабочего стола.
